## 🏥 Papollo Hospitals — Healthcare Data Analytics

> Interactive healthcare analytics dashboard built using Microsoft Power BI to analyze hospital operations, patient activity, doctors, diagnoses, billing, insurance, and bed occupancy.

### 🛠️ Tech Stack

`Power BI` `Power Query` `DAX` `Excel` `Data Visualization`

### 📊 Key Analysis

- Patient and admission analysis
- Doctor-related analysis
- Diagnosis analysis
- Billing amount analysis
- Health insurance analysis
- Bed occupancy analysis
- Admission, discharge and follow-up analysis
- Interactive filters and dashboard exploration

### 🔄 Workflow

Excel Dataset → Data Preparation → Power Query → DAX → Power BI Dashboard → Healthcare Insights

## 🏏 Rohit Sharma Career Analysis — Power BI

> Interactive Power BI dashboard analyzing Rohit Sharma's international cricket career across ODI, T20I, and Test formats.

### 🛠️ Tech Stack

`Power BI` `DAX` `Power Query` `Excel` `Data Visualization`

### 📊 Key Analysis

- Career runs, innings, average and strike rate
- ODI, T20I and Test performance comparison
- Year-wise run trends
- 50s and 100s analysis
- Boundary analysis
- Interactive format and year filters
